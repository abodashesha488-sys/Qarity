# قائمة صور ركن الأطفال — الموجة الرابعة (44 صورة)

المسار المتفق عليه: `assets/images/kids/<folder>/NN.jpg` — NN هو ترتيب الدرس داخل القائمة (01..NN)،
مشتق بالكود عبر `kidLessonImage(folder, index)` في `lib/features/children/children_lessons.dart`.
لا تعديل بالكود عند إضافة الصور؛ الشاشات تستخدم `errorBuilder` الآن (إيموجي/تفاح مرسوم).

## مواصفات الأسلوب الموحّدة (لكل الصور)
- رسم مسطّح طفولي modern flat children's-book vector، خلفية كريمي فاتحة، ألوان باستيل دافئة.
- بدون أي نص أو حروف داخل الصورة.
- 1024×1024 PNG → إعادة ضغط PIL إلى 360×360 JPG بجودة 82 قبل النسخ إلى assets.
- قصص الأنبياء: رموز only (سفينة، نار، عصا، حوت، قبة…) — **ممنوع تصوير أي نبي أو شخص**.

## بعد إضافة الصور
1. أنشئ `assets/images/kids/{num,wudu,salah,prophets,manners}/` وانسخ الصور بعد ضغط PIL.
2. سجّل الأصول في `pubspec.yaml`: `- assets/images/kids/<folder>/` **للمجلدات المكتملة فقط**
   (اختبار الحماية في `children_lessons_test.dart` يرفض تسجيل مجلد ناقص أو بقاء مكتمل غير مسجّل).
3. شغّل `flutter test` — الشاشات تلتقط الصور تلقائيًا عبر `kidLessonImage`.
